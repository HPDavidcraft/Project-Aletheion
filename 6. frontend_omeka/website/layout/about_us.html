/// 01.0 PROJECT ABSTRACT

The
Total
History
Mandate

Objective: To architect a federated, computationally active Digital Humanities infrastructure capable of ingesting, modeling, and analyzing the totality of human material culture and intangible heritage.

Operational Scope: Phase I covers the exhaustive documentation of all known archaeological sites, stratigraphy, and artifacts in Europe and West Asia, spanning the Paleolithic to Chalcolithic ages.

The "Decoupled" Paradigm: The system rejects the monolithic CMS model. It utilizes a headless Relational/Spatial backend (PostgreSQL/PostGIS) for rigorous data modeling, a Computational Layer (Jupyter) for analysis, and Omeka S strictly for narrative publication.

/// 02.0 THE TECHNICAL FEDERATION

System Architecture

  • Tier I: Data Core PostgreSQL 16+ / PostGIS / Apache Jena
  • Tier II: Logic & API Python (FastAPI) / Directus / MeiliSearch
  • Tier III: Computational Science OxCal / HDF5 / JupyterHub (K8s)
  • Tier IV: Visualization Geoserver (WMS) / Cantaloupe (IIIF)
  • Tier V: Interface Omeka S / Federated SPARQL 1.1

/// 03.0 4D-GIS INFRASTRUCTURE

The Deep Map State Machine

We do not simply place points on a map. We model the Stratigraphic Unit. The system validates Harris Matrices to ensure acyclic temporal relationships.

The "Deep Map" defines deterministic layer stacks per user selection (site / period / stratum / find), automatically switching base and overlay layers via Geoserver WFS.

/// 04.0 BIO-ARCHAEOLOGY MODULE

Genomics & Chronometry

Radiocarbon (C14): Raw uncalibrated dates are stored permanently. Bayesian calibration is performed on-demand via OxCal API wrappers.

aDNA Storage: High-throughput sequencing data is stored in HDF5/BioSQL containers, allowing for real-time generation of haplogroup dispersion graphs via Python pipelines.

/// 05.0 ONTOLOGY OF BELIEF

Theological Architecture

Ad-hoc naming is prohibited. All narrative elements are indexed using the Aarne-Thompson-Uther (ATU) or Thompson Motif-Index logic via SKOS.

We model the Liturgical Event as a temporal node with recurrence rules (RRULE), linked to astronomical alignments and temple features.

/// 06.0 IMMUTABLE PROTOCOLS

The "DO NOT" Protocol

  • NO FLAT DATA Stratum is not text. It is a relational entity.
  • NO LOCAL IMAGES All media must be served via IIIF.
  • NO HARDCODED DATES Use EDTF Integer Ranges.
  • NO INTERP. AS FACT Tag as "Structure", Interpret as "Temple".
  • NO PROPRIETARY FORMATS Excel/Word prohibited. CSV/JSON-LD only.

/// 08.0 THE AGORA

Citizen Science Integration

The Agora module allows for crowd-sourced transcription, classification, and pattern recognition. User contributions are recorded with provenance, using consensus aggregation algorithms weighted by contributor reliability scores (Gold/Silver/Bronze badges).
