    TRANSPARENCY & SAFEGUARDS

    What this demo can—and cannot—verify

    Trust previews and integrity panels demonstrate the guideline's display contract. All fixture inputs are fictional; no score is an assessment of evidence.

    Trust Score preview

    The guideline weights completeness (30%), bibliographic density (25%), spatial precision (20%), excavation methodology (15%), and data currency (10%). A score below 0.50 carries an uncertainty warning.

    Gold ≥ 0.80 Silver 0.55–0.79 Bronze 0.30–0.54 Incomplete < 0.30

    The fixture score uses invented component values to exercise badge states. In the real system, the server computes and validates the score from verified records.

    Publication requirements

    Published records require bibliographic links. The demo displays clearly marked citation slots, but their missing Zotero UUIDs, DOI data, page references, and quotations mean they are not valid citations.

    Every parent entity needs a media gallery and one or more assets with rights and IIIF manifest metadata. These fixture galleries intentionally show unresolved manifests and rights—not live IIIF media.

    Production wiring still required

    • PostgreSQL/PostGIS API for canonical records, valid geometries, EDTF validation, Harris Matrix checks, server-computed metrics, and immutable audit events.
    • Verified Getty AAT/SKOS terms, Zotero synchronization, real bibliographic metadata, and entity-level citation links.
    • Media ingest with checksums, rights review, versioned IIIF annotations, MinIO storage, and resolvable Cantaloupe manifests.
    • GeoServer/OGC and paleoclimate/orthophoto layers; real spatial clustering and provenance geometries.
    • Role-aware public API/export enforcement, conservation alerts, and authorized override workflow for restricted provenance.
